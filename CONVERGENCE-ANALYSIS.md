## 3. Convergence Gaps

### Gap 1: Entry Point Ambiguity
- FTS5 search: Symbol-centric
- Doc-reference: Bidirectional but manual
- No "give me everything about X" command

### Gap 2: Context Fragmentation
- Symbol graph: One view
- Doc symbols: Another view
- Relationships: Yet another view
- **Missing**: Unified context representation

### Gap 3: LLM-Friendly Output
- Current outputs: Human-readable terminal
- Missing: Machine-readable context
- No standardized format for LLM consumption

## 4. Proposed Convergence Point: LLMs.txt Generator

### Concept
```
Entry Point (file/symbol/doc)
    ↓
Context Extractor
    ↓
Ontology Serializer
    ↓
LLMs.txt (structured context)
```

### What It Should Include
1. **Primary Symbol Info**
   - Type, location, signature
   - TSDoc summary

2. **Direct Relationships**
   - Code dependencies (imports/exports)
   - Doc references (both directions!)
   - Test coverage

3. **Inferred Context**
   - Related symbols by naming pattern
   - Bidirectional doc links
   - Layer dependencies

4. **Usage Examples**
   - Test cases as examples
   - Actual usage in codebase

5. **Documentation**
   - Associated markdown docs
   - Inline TSDoc comments
   - Related conceptual docs

### Output Format (LLMs.txt)
```markdown
# Context: [EntryPoint]

## Summary
[One-line description]

## Location
File: src/path/to/file.ts:42
Type: class
Exported: Yes

## Purpose
[From @problem/@solves tags]

## Dependencies
### Imports
- moduleA: functionX, TypeY
- moduleB: default as Service

### Used By (Reverse Dependencies)
- featureZ: Calls this.method()
- testSuite: Tests functionality

## Documentation References
### This Code → Documentation
- [[FeatureName]]: Primary feature doc
- [[Architecture#Component]]: Architecture context

### Documentation → This Code (Inferred)
- [[GettingStarted]] references this as entry point
- [[APIReference]] includes in public API list

## Related Symbols
- Similar: OtherService (naming pattern)
- Collaborators: HelperUtil, ConfigManager
- Tested by: ServiceTest (100% coverage)

## Change Impact
If you modify this:
- 3 files will need updates
- 12 tests may be affected
- 2 docs need review
