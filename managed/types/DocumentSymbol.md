# [[DocumentSymbol]]

**Source**: `src/types/feature/doc-symbol.ts`

## Purpose

Type system for document symbols using `[[Symbol]]` notation.

## Document Symbol Types

### Primary Definition
- H1 heading with `[[Symbol]]`: `# [[FeatureName]]`
- One per document (canonical definition)
- Entry point for backlinks
- Defines the document's main topic

### Auxiliary Definition
- H2+ headings with `[[Symbol]]`: `## [[SubConcept]]`
- Multiple per document
- Sub-topics or related concepts
- Can be referenced independently

### Reference
- Inline `[[Symbol]]` in body text
- Links to other documents
- Creates bidirectional connections
- Builds knowledge graph

## Symbol Structure

See implementation: [[DocumentSymbol]]

**Key Properties**:
- `name`: Symbol name (without [[]])
- `type`: primary, auxiliary, or reference
- `filePath`: Document file path
- `line`: Line number
- `level`: Heading level (1-6, 0=inline)
- `content`: Description/context (optional)
- `section`: Section name for #Section refs (optional)

## Parsed Document Result

See implementation: [[ParsedDocSymbols]]

**Key Properties**:
- `filePath`: Document file path
- `primary`: H1 definition (optional)
- `auxiliaries`: H2+ definitions
- `references`: Inline [[refs]]
- `codeReferences`: Links to code
- `symbolFootnoteRefs`: Symbol footnote references
- `sourceFilePath`: From **Source**: pattern (optional)

## Code Reference

Links from docs to code:

See implementation: [[CodeReference]]

**Key Properties**:
- `text`: Link text
- `targetFile`: Source file path
- `targetSymbol`: Symbol name (optional)
- `targetMember`: Member name (optional)
- `line`: Line number (optional)

## Symbol Footnote

Special footnote references:
- `[^sym-XXX]`: Numbered symbol footnote
- `[^SymbolName]`: Named symbol footnote
- Used for additional context
- Auto-generated by parser

## Parsing Rules

### Primary Symbol
- Must be H1 (`# [[Name]]`)
- Only first H1 `[[Symbol]]` counts
- Sets document identity

### Auxiliary Symbols
- H2-H6 with `[[Symbol]]`
- All extracted as auxiliaries
- Create navigation checkpoints

### References
- Any `[[Symbol]]` in body text
- Not in headings
- Create bidirectional links
